# Platform workflows

Read the destination section. Use current official platform documentation for changing technical specifications, eligibility, ISBN rules, and commercial terms. Historical UI lessons below guide recovery, not hardcoded selectors or policies.

## IngramSpark

Match existing records by collection/title/edition/language/format/ISBN/profile. Preserve assigned ISBNs and approved metadata/settings. Copyright ownership, contributor identity, publisher credit, and free-ISBN imprint/ownership are separate fields; read the actual applicable terms. Do not assume another collection's acceptance applies.

Save manufacturing before uploading. Verify persisted trim, paper, binding, finish, duplex choice, final page count, markets, publication date, price/discount/returns, converted currencies, and actual positive compensation where required. A displayed value may be unsaved: type into the observed field, Tab, save, and reopen when necessary. Never use Up/Down arrows as a generic commit mechanism. For category/rights/dropdown errors, select the actual observed option and verify the intended final value persists.

Use exact official templates and files per ISBN/format. Paperback and ebook may share setup; hardcover can be separate. Observe the actual stage after Continue. For uploads use the documented chooser with exact absolute file paths. Wait for each selected file's filename, size, and uploaded date, not just 100% progress or an enabled Continue. Confirm content and metadata validation independently. Retry only missing or superseded files, preserving successful uploads.

Read final title group, terms, and fee display. Complete authorized no-fee submission once per group; save waiting-for-confirmation state before clicking. Verify Congratulations/Complete or dated submitted account records for **each format**, save URL/screenshot/time/hash, and close that completed book tab. After uncertain responses inspect Titles before retrying; the user may have completed submission independently. Search can briefly show stale rows; verify exact ISBN after refresh. Do not reuse stale element IDs or reload active file selections.

### Proofs, revisions, distribution

Processing can block revisions or new proofs. Do not force an old proof URL or approve a stale proof while a replacement is pending. Download the current proof and hash it; compare against the exact submitted revision. Establish wrapper/cover/interior offsets from that actual file. Compare every interior page's normalized text where possible, inspect render differences, visually review critical pages and covers, and state review scope honestly. Expected PROOF marks, manufacturing pages, and barcodes require separate treatment from real defects. This is not a new complete copyedit or physical print proof. An unchanged current-download hash may preserve the applicability of a previous review.

New uploads invalidate previous approval eligibility. When authorized only to approve suitable files, select the plain publisher-approves-title option if available; the option mentioning printing/distribution/sale has broader scope. Verify exact current wording and effect. Proof approval and Enable Distribution are separate actions. Verify the resulting per-title status and distribution indicator; do not infer retailer visibility. Never make unrelated undo/revision/order actions to resolve a confusing status without scope for them.

## KDP

Match title + edition + format + platform ID/ISBN. Keep existing and new editions distinct; link formats within the correct edition group. Reconcile Bookshelf before creating or retrying. A quota/title limit is an external blocker: preserve ready packages and report it accurately.

Build KDP-specific paperback/hardcover interiors and official-template wraps using final pagination. Do not substitute an IngramSpark wrap or accidentally overwrite its interior. Verify Kindle files in the converted preview as well as local EPUB validation. Use truthful per-book AI disclosures and rights; original text, editing, generated content, and cover provenance can differ among books.

Enter the edition's approved metadata, actual available categories/keywords, territories, prices, and enrollment choice. Do not carry IngramSpark discounts/returns or a previous title's Kindle Select choice into KDP as defaults. Save and verify values, await processing, resolve preview errors, and complete authorized publishing submission. After a transient error inspect existing state and resume saved Details/Content if appropriate; never create a duplicate as a recovery shortcut.

Verify confirmation and re-read Bookshelf for each format. Distinguish submitted/in review, blocked, and live. Record platform IDs, dated labels, file hashes, preview evidence, and blockers. A previously live edition can later be blocked; refresh status when asked.
